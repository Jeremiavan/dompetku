# 💰 Dompetku — Catatan Keuangan Harian

Aplikasi catatan keuangan pribadi berbasis web. Simpan pemasukan & pengeluaran, pantau hutang, dan lihat laporan bulanan.

## Fitur
- 📊 Dashboard ringkasan bulanan (pemasukan, pengeluaran, saldo)
- ➕ Input transaksi pemasukan & pengeluaran
- 📋 Laporan & riwayat transaksi dengan filter
- 💳 Manajemen hutang dengan tracker cicilan
- 📈 Analisis 50/30/20 (Kebutuhan / Keinginan / Tabungan)
- 💾 Data tersimpan di localStorage browser

## Deploy
Dibuat dengan HTML, CSS, JS murni — tanpa framework, tanpa backend.

Live di: [dompetku.vercel.app](https://vercel.com)
